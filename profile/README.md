## Build with us

### [Chronicle](https://github.com/Chatixia-AI/agents-chronicle)

**A memory for your coding agents.**

Keep coding-agent sessions and imported chats on your own machine. Search past work, revisit decisions, and share extracted knowledge with your agents through MCP.

[Get started](https://chronicle.chatixia.net/) · [Download the macOS app](https://github.com/Chatixia-AI/agents-chronicle/releases/latest) · [Source code](https://github.com/Chatixia-AI/agents-chronicle)

### [chatixia-mesh](https://github.com/Chatixia-AI/chatixia-mesh)

**Agents that connect directly.**

A working peer-to-peer agent network built with Rust, Python, and WebRTC. Explore the code, the architecture decisions, and a course that explains how it works from the ground up.

[Explore the docs](https://mesh.chatixia.net) · [Start the course](https://blog.chatixia.net) · [Source code](https://github.com/Chatixia-AI/chatixia-mesh)
